StreamStats Беглецова Всеволода для аеализа данных.

Функционал:
python -m streamstats INPUT --format FORMAT --output OUTPUT.json --skip-invalid

INPUT - Файл, который вы хотите проанализировать

FORMAT - формат файла (jsonl или csv)

OUTPUT - имя файла с логами

Флаг --skip-invalid ставится по желанию, если хотите пропустить ошибки

python -m --help - узнать об использовании StreamStats

Пользуйтесь на здоровье!
